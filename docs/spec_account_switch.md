# メールアカウント切り替え機能 仕様書

## 技術スタック
- Streamlit UI
- Gmail API（google-auth-oauthlib）
- token.json（認証情報ファイル）

## 機能仕様

### 1. 現在のアカウント表示
- `gmail.users().getProfile()` でログイン中のメールアドレスを取得
- アプリ上部またはヘッダーに「接続中: xxx@gmail.com」を常時表示

### 2. アカウント切り替え
- 設定タブに「🔄 アカウントを切り替える」ボタンを追加
- ボタン押下 → token.json を削除 → セッションリセット → 再認証フロー

### 3. ローカル vs Streamlit Cloud の動作差異
| 環境 | 切り替え方法 |
|------|------------|
| ローカル | ブラウザが開いてGoogleログイン選択 |
| Streamlit Cloud | GMAIL_TOKEN_JSON Secretを新しいアカウントのtokenに更新が必要（案内を表示） |

## UIの変更箇所
- ヘッダー付近：接続中アカウントのバッジ表示
- 設定タブ（新タブ「📧 アカウント」）：アカウント情報＋切り替えボタン

## エラーケース
| ケース | 対応 |
|--------|------|
| Gmail API接続失敗 | 「接続エラー」表示・再接続ボタン |
| token期限切れ | 自動リフレッシュ、失敗時は再認証案内 |
